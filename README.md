# SIRAT

> **Archived Flutter application prototype. This repository is not maintained or supported.**

SIRAT explored a multilingual mobile companion for prayer times, qibla direction, daily content, reminders, and Firebase-backed account features.

## Archive status

- The application and cloud functions were not rebuilt or deployed during archival.
- Committed Firebase client configuration was removed from the current tree. A new evaluator must create a separate Firebase project and generate fresh platform configuration.
- Location, account, analytics, notification, and religious-content flows require current privacy, consent, security, and content review before any reuse.
- No store publication, production deployment, active backend, or service-availability claim is made.

The source remains online for historical inspection only. There is no designated maintained successor; current public work is listed in the [open-source portfolio](https://www.mehmeterendereli.com/en/open-source).
